# قالب وب‌سایت «فناوری اطلاعات آمل نوین» — راهنمای استفاده

قالب استاتیک (HTML + CSS + JS)، راست‌به‌چپ و کاملاً فارسی، با ۵۸ صفحه، بهینه‌شده برای سئو، سرعت و موبایل.
لوگو، رنگ‌ها (سرمه‌ای `#272869` و فیروزه‌ای `#13a89e`) و ساختار آدرس‌ها از سایت فعلی `amolnovin.ir` گرفته شده است.

## پوشه‌ها

| مسیر | چیست؟ |
|---|---|
| `amolnovin-theme/` | **خود سایت** (فقط همین پوشه را روی هاست آپلود کنید) |
| `amolnovin-generator/` | **سورس تولیدکننده‌ی** پایتون (محتوا در `data/`، قالب‌های HTML در `templates/`، CSS/JS در `static/`) |
| `docs/keyword-research.md` | تحقیق کلمات کلیدی (۶ کلمه‌ی اصلی × ۵ کلمه‌ی مرتبط + ۲۰ نوع سایت) |
| `docs/keywords.csv` | همان جدول برای Excel / Google Sheets |
| `docs/seo-audit.md` | گزارش ممیزی خودکار سئو و لینک‌ها (۰ خطا) |

## اجرای محلی

- **ساده‌ترین راه:** فایل `amolnovin-theme/index.html` را در مرورگر باز کنید (حتی بدون وب‌سرور؛ لینک‌ها خودکار اصلاح می‌شوند).
- **پیشنهادی:** `cd amolnovin-theme && python3 -m http.server 8080` و باز کردن `http://localhost:8080`
  (در مرورگر Firefox برای صفحه‌های داخلی، حالت فایل ممکن است فونت را نشان ندهد؛ با وب‌سرور محلی مشکلی نیست).

## ویرایش اطلاعات و بازسازی

همه‌ی اطلاعات تماس، قیمت پایه و شبکه‌های اجتماعی در **یک فایل** است: `amolnovin-generator/config.py`.

```bash
cd amolnovin-generator
pip install jinja2                                # فقط برای ساخت سایت (ابزارهای کنترل کیفیت: requirements.txt)
python3 build.py                                  # خروجی در ../amolnovin-theme
python3 tools/audit.py                            # ممیزی سئو، لینک‌ها، عنوان‌ها و تصاویر
```

| می‌خواهم … | فایل |
|---|---|
| شماره، ایمیل، آدرس، لینک اینستاگرام/تلگرام را عوض کنم | `config.py` |
| متن یکی از ۲۰ نوع سایت را ویرایش یا نوع جدید اضافه کنم | `data/types_a.py` ، `data/types_b.py` |
| متن صفحه‌های خدمات، وردپرس، آمل، تعرفه، درباره‌ی ما | `data/pages_a.py` ، `pages_b.py` ، `pages_c.py` |
| پروژه‌ی جدید به نمونه‌کار اضافه کنم | `data/portfolio.py` + تصویر در `static/img/portfolio/` |
| افزونه‌ی جدید به فروشگاه اضافه کنم | `data/store.py` |
| مقاله‌ی جدید بنویسم | `data/blog.py` |
| عددهای ماشین‌حساب هزینه | `data/common.py` (بخش `CALC`) |
| رنگ‌ها، فونت، فاصله‌ها | `static/css/01-base.css` (متغیرهای `:root`) |

اگر پایتون ندارید، می‌توانید فایل‌های HTML داخل `amolnovin-theme/` را مستقیم ویرایش کنید؛ فقط توجه کنید با اجرای دوباره‌ی `build.py` تغییرات دستی بازنویسی می‌شود.

## انتشار روی هاست

1. محتوای `amolnovin-theme/` را در `public_html` آپلود کنید (هاست Apache/LiteSpeed با cPanel یا DirectAdmin).
2. بعد از فعال شدن SSL، خطوط کامنت‌شده‌ی HTTPS در `.htaccess` را فعال کنید.
3. در Nginx: `try_files $uri $uri/ =404;` + `error_page 404 /404.html;` و ۳۰۱ آدرس‌های قدیمی (در `.htaccess` فهرست شده‌اند).
4. فرم‌ها: اگر PHP دارید، `api/lead.php` ایمیل می‌فرستد (آدرس گیرنده را در فایل عوض کنید). اگر نه، فرم‌ها خودکار به **واتساپ** هدایت می‌شوند.
5. در Google Search Console سایت را ثبت و `https://amolnovin.ir/sitemap.xml` را ارسال کنید؛ پروفایل Google Business را برای آدرس آمل کامل کنید.

## سئو؛ چه چیزهایی انجام شده؟

- یک `<h1>` در هر صفحه، عنوان و توضیح متای یکتا، canonical، hreflang، Open Graph و Twitter Card با **تصویر اختصاصی ۱۲۰۰×۶۳۰ برای هر صفحه**.
- داده‌ی ساختاریافته (JSON-LD): `ProfessionalService/LocalBusiness`، `WebSite`، `BreadcrumbList`، `Service` (با قیمت شروع)، `FAQPage`، `BlogPosting`، `CreativeWork`، `ItemList`، `CollectionPage`، `ContactPage`، `AboutPage`. هیچ امتیاز/نظر ساختگی در اسکیما نیست.
- «خلاصه‌ی پاسخ» (TL;DR) بالای صفحه‌ها، سوالات متداول، جدول‌های مقایسه و `llms.txt` برای دیده‌شدن در پاسخ‌های هوش مصنوعی (GEO/AEO).
- سرعت: فونت Vazirmatn خودمیزبان و سبک‌شده (۷۰ کیلوبایت)، CSS حدود ۱۹ کیلوبایت و JS حدود ۷ کیلوبایت (gzip)، تصاویر WebP با ابعاد مشخص و بارگذاری تنبل، بدون وابستگی به CDN یا کتابخانه‌ی خارجی.
- دسترس‌پذیری: لینک «پرش به محتوا»، ناوبری با کیبورد، حالت تاریک/روشن، احترام به `prefers-reduced-motion`.
- ۲۰ صفحه‌ی نوع سایت و ۱۲ مطالعه‌ی موردی، همه با لینک‌دهی داخلی و مسیر breadcrumb.

## نکات قابل بازبینی پیش از انتشار

این موارد را عمداً علامت می‌زنیم تا اشتباهی منتشر نشود:

1. **شماره‌ی تماس:** طبق تأیید شما شماره‌ی اصلی `0933 202 1365` است و در همه‌ی صفحه‌ها (نوار بالا، منوی موبایل، فوتر، دکمه‌های تماس و واتساپ، اسکیما و `llms.txt`) فقط از `config.py` خوانده می‌شود؛ برای هر تغییر بعدی فقط همان‌جا را ویرایش کنید. (در سایت فعلی ممکن است هنوز شماره‌ی `0939 202 1365` در بعضی صفحه‌ها و شماره‌ی نمونه‌ی `0912 345 6789` در صفحه‌ی کدنویسی مانده باشد؛ هنگام انتقال محتوا یکسانشان کنید.)
2. **قیمت:** در سایت فعلی «شروع از ۱۷ میلیون» و «۲۰ میلیون» هر دو آمده؛ قالب ۱۷ میلیون را (مطابق جدول و سوالات متداول) به‌کار برده است.
3. **ماشین‌حساب هزینه:** فقط پایه‌ی ۱۷ میلیون رسمی است؛ ضرایب سایر انواع و امکانات نمونه‌ی پیش‌فرض است و باید با تعرفه‌ی واقعی شما اصلاح شود (`data/common.py`).
4. **سرفصل‌های دوره‌ی وردپرس** و **توضیح افزونه‌های فروشگاه** بر اساس نام و تصویر نوشته شده‌اند و باید با مشخصات واقعی تطبیق داده شوند.
5. **نمونه‌کارها:** فقط اطلاعات تأییدشده (نام کارفرما، دسته، فناوری، لینک) استفاده شده و هیچ آمار ساختگی (فروش، ترافیک) درج نشده است. تاریخ شروع فقط برای ۳ پروژه که در سایت فعلی ثبت است آمده. آدرس زنده‌ی ویلا سره، چوبین دکور و کابل حیدری در سایت فعلی نبود و لینک ندارند.
6. **مقاله‌های وبلاگ** نمونه‌اند؛ مقاله‌های واقعی خودتان را جایگزین کنید.
7. **شبکه‌های اجتماعی:** لینک‌ها در `config.py` خالی است و نمایش داده نمی‌شود؛ پر کنید تا در پاورقی و اسکیما بیایند.
8. **متن حریم خصوصی** نمونه است و باید با نظر مشاور حقوقی تکمیل شود.
9. **عکس مدیر و تصویر پروانه‌ی کسب** از سایت فعلی گرفته شده است؛ اگر نمی‌خواهید منتشر شود، از `data/pages_c.py` و `config.py` حذف کنید.

### مشکلاتی که در سایت فعلی دیدیم (در قالب جدید رفع شده)

- حدود ۱۲ لینک نمونه‌کار در `/wordpress-web-design/` به `?p=ID` اشاره می‌کنند که ۴۰۴ می‌دهد.
- صفحه‌ی پیش‌نویس خانه شامل شورت‌کد جا‌مانده‌ی `[rev_slider …]` و یادداشت‌های داخلی است.
- مُهر تاریخ «خرداد ۱۴۰۴» در صفحه‌ی تعرفه قدیمی است.
- آمارهای بدون منبع در صفحه‌ی سئو (۹۳٪، ۷۵٪، ۵٫۶۶×) در قالب استفاده نشد.

## مجوزها

فونت Vazirmatn (SIL OFL)، آیکن‌ها از Lucide (ISC) و آیکن‌های برند از Simple Icons (CC0). لوگو و تصاویر نمونه‌کار متعلق به آمل نوین و کارفرمایان آن است.

## بازتولید داده‌ها (اختیاری)

- `tools/suggest_mine.py` — استخراج دوباره‌ی پیشنهادهای Google Suggest برای هر کلمه (خروجی در `_assetsrc/keyword-data/`) و سپس `python3 tools/kw_report.py` برای ساخت دوباره‌ی `docs/keyword-research.md`.
- `tools/prepare_brand.py` / `prepare_icons.py` / `prepare_images.py` — ساخت دوباره‌ی لوگوی برداری، فاویکن‌ها، فونت سبک‌شده و تصاویر از منابع داخل `_assetsrc/` (نیازمند `requirements.txt`).
- `tools/prepare_sprite.py` — بروزرسانی آیکن‌ها (نیازمند `npm i lucide-static simple-icons` داخل `_assetsrc/node`)؛ خروجی آماده در `data/icons.json` موجود است.
