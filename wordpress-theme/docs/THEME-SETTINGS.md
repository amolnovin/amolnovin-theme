# پنل تنظیمات قالب و هماهنگی افزونه‌ها

همه‌ی تنظیماتِ غیرمحتوایی قالب در یک صفحه جمع شده است: **پیشخوان ← آمل نوین** (`admin.php?page=amol-theme`).
مقادیر در یک گزینه‌ی وردپرس (`amol_options`) و به تفکیک تب ذخیره می‌شوند؛ هر ماژول قالب آن‌ها را از
`App\Support\Options` می‌خواند.

| تب | کلید گروه | چه چیزی را کنترل می‌کند |
|---|---|---|
| بهینه‌سازی سرعت | `speed` | متاهای اضافی، oEmbed، CSS بلوک‌ها، Dashicons، `?ver=`، jQuery، Lazy loading، Heartbeat، نگارش‌ها، preload فونت، preconnect، Speculative Loading |
| سئو | `seo` | موتور سئوی قالب، sitemap/llms/manifest، noindex سایت، robots.txt، OG پیش‌فرض، توییتر، کدهای تأیید گوگل/Bing، BreadcrumbList، نوع سازمان، تعداد نوشته در صفحه |
| هدر و فوتر | `header_footer` | نوار بالای هدر، هدر چسبان، دکمه‌ی CTA، نوار اعلان (با امکان بستن)، متن فوتر، کپی‌رایت، بازگشت به بالا، کد سفارشی head/body/footer |
| شمارنده‌ها | `counters` | روشن/خاموش، مدت انیمیشن، ردیف‌های شمارنده‌ی صفحه‌ی اصلی و نمونه‌کارها با متغیرهای پویا |
| فرم‌ها و کپچا | `forms` | کپچا در فرم‌های قالب و دیدگاه، honeypot، محدودیت نرخ، پیام‌های موفقیت/خطا |
| افزونه‌ها و فروشگاه | `integrations` | وضعیت چهار افزونه، شورت‌کد قطعه‌کدها، منبع صفحه‌ی فروشگاه، سازگاری بسته‌ی امنیتی |
| بروزرسانی قالب | `updates` | منبع manifest، کانال، بررسی خودکار، اعمال/بازگردانی پچ، بارگذاری پچ آفلاین |
| ابزارها و اطلاعات | — | وضعیت سایت (نسخه، پیوند یکتا، برگه‌ها)، میان‌بر تنظیمات خواندن/سفارشی‌ساز، بازسازی فهرست جست‌وجو، فهرست قطعه‌کدها |

بخش‌های محتوایی همچنان جای خودشان هستند: برند/تماس/قیمت در **سفارشی‌ساز**، فهرست‌های مشترک در
**داده‌های اشتراکی قالب**، متن صفحه‌ها در ویرایشگر ساختاری هر برگه و ورود نمونه در **ابزارها**.

## ۱. بهینه‌سازی سرعت

| گزینه | پیش‌فرض | اثر |
|---|---|---|
| حذف متاهای اضافی | روشن | `wp_generator`، RSD، WLW، shortlink، لینک REST، emoji |
| خاموش‌کردن oEmbed | روشن | حذف `wp-embed.js` و مسیر REST oEmbed |
| حذف CSS بلوک‌ها | روشن | صفحه‌های بدون بلوک واقعی، CSS گوتنبرگ را لود نمی‌کنند |
| حذف Dashicons | روشن | فقط برای بازدیدکنندگان؛ کاربران واردشده آیکن‌ها را می‌بینند |
| حذف `?ver=` | روشن | کش طولانی‌مدت فایل‌های ایستا (برای کاربر واردشده اعمال نمی‌شود) |
| حذف jQuery | خاموش | فقط اگر هیچ افزونه‌ای به آن نیاز ندارد |
| Lazy loading | روشن | خاموش‌کردن، `wp_lazy_loading_enabled` را غیرفعال می‌کند |
| Heartbeat | کند (۶۰s) | فقط بخش عمومی |
| نگارش‌ها | ۵ | `wp_revisions_to_keep` |
| preload فونت | روشن | `<link rel=preload>` برای وزیرمتن |
| preconnect | — | هر خط یک دامنه‌ی خارجی |
| Speculative Loading | خاموش | مطابق رفتار قالب HTML |

## ۲. سئو

- موتور سئوی قالب (`App\Seo\Head`) با فعال‌بودن Yoast/Rank Math/AIOSEO/SEOPress/The SEO Framework خودکار خاموش می‌شود.
- `site_noindex` هم متای `robots` و هم `robots.txt` را noindex می‌کند (حالت پیش‌نمایش/تعمیر).
- خطوط اضافی robots.txt فقط با دستورهای مجاز (`Disallow`, `Allow`, `User-agent`, `Sitemap`) ذخیره می‌شوند.
- تصویر پیش‌فرض Open Graph فقط وقتی استفاده می‌شود که صفحه تصویر اختصاصی/شاخص نداشته باشد.
- BreadcrumbList با خاموش‌کردن گزینه از گراف JSON-LD حذف می‌شود (بقیه‌ی گراف دست‌نخورده می‌ماند).
- `posts_per_page` روی صفحه‌ی وبلاگ، آرشیوها و جست‌وجو اعمال می‌شود.

## ۳. هدر و فوتر

- نوار اعلان: متن چندخطی + لینک اختیاری؛ انتخاب «بستن» کاربر در `localStorage` ذخیره می‌شود.
- خاموش‌کردن «هدر چسبان»، کلاس `no-sticky-header` را به `body` می‌دهد (CSS در `06-wp.css`).
- کد سفارشی head/body/footer فقط برای دارندگان `unfiltered_html` خام ذخیره می‌شود؛ برای بقیه با `wp_kses_post` فیلتر می‌گردد.

## ۴. شمارنده‌ها

هر خط: `عدد|پسوند|برچسب` — مثال `15|+|سال تجربه`.
متغیرهای پویا (همیشه از محتوای واقعی محاسبه می‌شوند):

| متغیر | مقدار |
|---|---|
| `{types}` | تعداد «انواع سایت» |
| `{projects}` | تعداد نمونه‌کارها |
| `{detail}` | نمونه‌کارهای دارای مطالعه‌ی موردی |
| `{posts}` | تعداد نوشته‌های منتشرشده |
| `{years}` | سال تجربه (سال جاری شمسی − سال تأسیس) |
| `{founded}` | سال تأسیس شمسی |

مدت انیمیشن روی `<html data-counter-dur>` نوشته می‌شود و `main.js` آن را می‌خواند؛ مقدار `۰` (یا خاموش‌بودن
تب) عدد نهایی را بی‌حرکت نشان می‌دهد.

## ۵. فرم‌ها و کپچا

- فرم مشاوره یک فرم REST است (`/wp-json/amolnovin/v1/lead`)؛ کپچا داخل فرم رندر می‌شود و **سمت سرور** پیش از
  ذخیره/ایمیل بررسی می‌شود (fail-closed).
- فیلدهای استفاده‌شده از افزونه: `wpmc_answer`، `wpmc_token`، `wpmc_website`.
- در حالت «خودکار» برای دیدگاه‌ها، اگر محافظت دیدگاهِ خود افزونه روشن باشد قالب دخالت نمی‌کند (جلوگیری از دو کپچا).
- محدودیت نرخ بر اساس IP و با transient است؛ `۰` یعنی بدون محدودیت.

## ۶. هماهنگی افزونه‌ها

| افزونه | تشخیص | رفتار قالب |
|---|---|---|
| **Custom HTML Snippets 3.0.0** | `AmolNovin\CHS\VERSION` / `custom_snippet` / `my_snippet` | شورت‌کد در محتوا، خلاصه‌ها و بخش «قطعه کد سفارشی»؛ انتخاب قطعه‌کد برای بالای وبلاگ و پایین وبلاگ؛ `do_shortcode` در بخش HTML |
| **WP Plugin Market Manager** | `WPLM_VERSION` / `WPLM\Plugin` / `wplm_store` | صفحه‌ی `/wplm-store/` شورت‌کد `[wplm_store]` را رندر می‌کند (محصول، سبد، پرداخت، حساب کاربری)؛ دکمه‌ی «اتصال صفحه‌ی فروشگاه» گزینه‌های افزونه را به همین برگه وصل می‌کند؛ CPT داخلی قالب در این حالت از منو پنهان می‌شود |
| **WP Math Captcha 1.x** | `WP_MC_Captcha` | کپچا در فرم مشاوره + بررسی سمت سرور؛ دیدگاه‌ها به‌صورت خودکار |
| **Novin Security Suite 1.3.x** | `NSH_VERSION` / `nsh()` | باز نگه‌داشتن مسیر REST عمومی وقتی «الزام ورود برای REST» روشن است؛ جلوگیری از ارسال دوباره‌ی هدرهای امنیتی؛ نمایش وضعیت در پنل |

نکته‌ها:

- مسیرهای عمومی REST قابل تنظیم‌اند: `add_filter('amol/security/public_rest_routes', …)`.
- وضعیت هر افزونه (فعال/نصب‌شده/نصب‌نشده + نسخه) در تب «افزونه‌ها و فروشگاه» دیده می‌شود.
- هیچ‌کدام از این هماهنگی‌ها وابستگی سخت ایجاد نمی‌کند؛ با غیرفعال‌شدن افزونه، قالب به رفتار پیش‌فرض خود برمی‌گردد.

## ۷. بروزرسانی قالب

راهنمای کامل: [`UPDATES.md`](UPDATES.md). خلاصه:

- کاتالوگ: `wordpress-theme/updates/manifest.json` (+ `manifest.schema.json`).
- بسته: `updates/patches/amolnovin-<from>-to-<to>.zip` فقط با فایل‌های تغییرکرده.
- اسکریپت ساخت: `scripts/make-patch.sh <from-ref> <to-ref> <version> "notes" [base-version]`.
- پشتیبان: `wp-content/uploads/amolnovin-backups/…`؛ بازگردانی با یک کلیک.

## ۸. ابزارها و اطلاعات

تب آخر تنظیمی ندارد؛ وضعیت را نشان می‌دهد و چند کار سریع انجام می‌دهد:

- نسخه‌ی قالب، وردپرس، PHP، ساختار پیوندهای یکتا، برگه‌ی صفحه‌ی اصلی و برگه‌ی نوشته‌ها، آدرس فروشگاه و
  وضعیت فایل جست‌وجو.
- میان‌بر به تنظیمات خواندن، پیوندهای یکتا، سفارشی‌ساز، داده‌های اشتراکی و ورود محتوای نمونه.
- دکمه‌ی **بازسازی فهرست جست‌وجو** (`uploads/amolnovin/search-index.js`).
- فهرست قطعه‌کدهای افزونه‌ی Custom HTML Snippets همراه با شورت‌کد آماده.
